1"""自治体カスタム前処理の基底クラス。 

2 

3事業者は ``BasePreprocessor`` を継承し、以下の 4 メソッドを必要に応じて実装する: 

4 

5- ``validate``: 生データの入力規則チェック（自治体固有） 

6- ``transform_children``: スコアランキング・兄弟パターンの計算 

7- ``transform_daycares``: 保育所データの変換（通常は不要） 

8- ``transform_output``: 出力ファイルの列・行の加工（通常は不要）

20class BasePreprocessor: 

21 """自治体カスタム前処理の基底クラス。デフォルト実装はすべてパススルー。 

22 

23 ``MatchingService`` のコンストラクタに渡すことで前処理を有効にする:: 

24 

25 from chilmai.generic import MatchingService 

26 from mytown.preprocessor import MyTownPreprocessor 

27 

28 service = MatchingService(preprocessor=MyTownPreprocessor()) 

29 result = service.match(...) 

30 

31 パイプラインの順序: 

32 

33 1. ``parse`` — ファイル読込・列名マッピング 

34 2. ``validate`` — 自治体固有バリデーション（ここでエラーがあれば以降はスキップ） 

35 3. ``transform_children`` / ``transform_daycares`` — score_1〜N・sibling_pattern の計算 

36 4. ``ValidationService.validate`` — ChilmAI 汎用バリデーション 

37 5. ``matcher.match`` — マッチング実行 

38 6. ``transform_output`` — 出力 DataFrame の列・行を加工

64 def transform_children(self, df: pd.DataFrame) -> pd.DataFrame: 

65 """申込者データを変換し、スコア列と ``sibling_pattern`` 列を追加する。 

66 

67 ``validate`` でエラーがなかった場合のみ呼ばれる。 

68 元 DataFrame を変更せず、コピーを返すことを推奨する。 

69 

70 ``score_N`` はタイブレーカーまで含んだ完全な優先順位スコアでなければならない。 

71 基礎点が同じ申込者が複数いる場合に同値だとマッチング内での優先順位が不定になる。 

72 希望施設ごとの点数列が基礎点のみを表す場合は共通タイブレーク列と組み合わせて 

73 一意なスコアを生成すること 

74 （``examples/sample_preprocessor.py`` の ``PerPreferenceScorePreprocessor`` 参照）。 

75 

76 Args: 

77 df: 申込者データ（列名マッピング適用済み）。 

78 

79 Returns: 

80 以下の列を追加した DataFrame: 

81 

82 - ``score_1``（整数）: 全保育所共通のベーススコア。``score_N`` が存在しない 

83 希望施設への点数として使われる。全施設で同じ点数ルールの場合は 

84 この列だけ返せばよい。 

85 - ``score_2``, ``score_3``, ...（整数・任意）: 第 N 希望施設への個別スコア。 

86 元データに希望施設ごとの点数列がある場合（例: 第1希望は50点・ 

87 兄弟在籍の第2希望は55点など）に設定する。``pref_N`` 列に対応する 

88 施設に適用され、``score_N`` がない希望は ``score_1`` にフォールバックする。 

89 - ``sibling_pattern``（"1"〜"7" または空文字）: きょうだいパターン番号。 

90 """ 

91 return df

125 @staticmethod 

126 def rank_by( 

127 df: pd.DataFrame, 

128 rules: list[tuple[str, str]], 

129 ) -> pd.Series: 

130 """複数列のソートルールから整数ランクを計算する。 

131 

132 ``transform_children`` 内で ``score_1`` や ``score_N`` を計算する際に使う。 

133 戻り値の整数は「高いほど優先度が高い」ため、そのままスコア列に代入できる。 

134 

135 Args: 

136 df: 申込者 DataFrame。 

137 rules: ソートルールのリスト。各要素は ``(列名, "asc"|"desc")`` のタプル。 

138 例: ``[("指数合計", "desc"), ("優先順位2", "asc")]`` 

139 空リストを渡すと入力順のまま n, n-1, ..., 1 を返す。 

140 

141 Returns: 

142 df と同じインデックスを持つ ``pd.Series[int]``。 

143 値は 1〜len(df) の整数で、高いほど優先度が高い。 

144 NaN 値は最低優先（リスト末尾）として扱われる。 

145 全キーが同値の行は入力順を維持する（安定ソート）。 

146 

147 Raises: 

148 ValueError: direction が ``"asc"`` でも ``"desc"`` でもない場合。 

149 """ 

150 n = len(df) 

151 if not rules: 

152 return pd.Series(range(n, 0, -1), index=df.index) 

153 

154 cols = [] 

155 ascending = [] 

156 for col, direction in rules: 

157 if direction not in ("asc", "desc"): 

158 raise ValueError(f"rank_by の direction は 'asc' か 'desc' のみ有効です: {direction!r}") 

159 cols.append(col) 

160 ascending.append(direction == "asc") 

161 

162 sorted_idx = df.sort_values(by=cols, ascending=ascending, na_position="last", kind="stable").index 

163 rank_values = pd.Series(range(n, 0, -1), index=sorted_idx) 

164 return rank_values.reindex(df.index)
