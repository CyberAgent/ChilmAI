# セキュリティ

セキュリティ上の懸念がある内容は、公開 Issue や Pull Request に投稿しないでください。報告方法はリポジトリの [SECURITY.md](https://github.com/CyberAgent/ChilmAI/blob/main/SECURITY.md) を参照してください。

## データの扱い

ChilmAI は保育所利用調整に関わるデータ構造を扱います。実データには個人情報や機微な情報が含まれる可能性があるため、開発、バリデーション、問い合わせでは合成データを利用してください。

## 組み込み時の確認事項

Python API やサーバ API を業務システムに組み込む場合は、少なくとも以下を別途設計してください。

- 認証と認可
- 入力ファイルと結果ファイルの保管方針
- 監査ログ
- 通信経路と保存データの保護
- 運用監視
- 脆弱性対応のプロセス
