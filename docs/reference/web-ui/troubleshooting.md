# 困ったとき

起きている症状に近い見出しを選んで、対処方法を確認してください。エラーコード（`E101` など）が表示されている場合は、下の「エラーコード一覧」から探すのが早道です。

## 起動したがブラウザが開かない

黒いウィンドウは開いたままにして、手動でブラウザを開き `http://127.0.0.1:8501` を入力してください。それでも開かず、黒いウィンドウに `error while attempting to bind on address ...:8501` という英文が出てすぐ終了する場合は、別の ChilmAI（または別のソフト）が同じ通信窓口（ポート 8501）を使用中です。開いている ChilmAI をすべて閉じてから起動し直してください。

## データ確認でエラーが出る

エラーメッセージのコード（`E101` など）を下の一覧で確認してください。多くは「列名の対応づけ」（E1xx）か「データの値」（E2xx）の問題で、[自分のデータで使う](prepare-data.md) の該当する手順で解消できます。

## 文字コードが原因で読み込みに失敗する（E405）

**「ファイルの文字コードが UTF-8 ではないため読み込めませんでした」（E405）** と表示される場合は、CSV ファイルの文字コード（文字を保存する方式）が原因です。Excel の「名前を付けて保存」で既定の **「CSV (コンマ区切り) (\*.csv)」** を選ぶと Shift-JIS で保存され、ChilmAI では読み込めません。保存形式の一覧から **「CSV UTF-8 (コンマ区切り) (\*.csv)」** を選んで保存し直すか、CSV ではなく Excel 形式（.xlsx）のままアップロードしてください。詳しくは [選考の実行と結果の見方](run-results.md#upload) を参照してください。

## マッチングでエラーが出る・処理が終わらない

- **「マッチングが実行不可能です（INFEASIBLE）」（E501）**：条件の組み合わせが厳しすぎて、成り立つ割り当てが存在しません。きょうだい条件（特に [同保系（1〜3）](prepare-data.md#siblings)：新たに割り当てる保育所をきょうだい全員で 1 か所までに限るパターン）や入力データの不整合を確認してください
- **「制限時間内にマッチング結果が確定しませんでした」（E502）**：データ規模が大きい場合に起こります。きょうだい世帯の数が非常に多くないか確認し、解消しない場合はログを添えて [不具合の報告](#report) をしてください
- **数分待っても「処理中」のまま**：黒いウィンドウにエラーが出ていないか確認します。大規模データでは数分かかることがありますが、それ以上進まない場合は ChilmAI を終了して再起動してください

??? note "エラーコード一覧"
    **E1xx：設定の問題（列名の対応づけ）**

    | コード | 内容 | 対処 |
    |---|---|---|
    | E101 / E102 | 申込者／保育所ファイルに必要な列が見つからない | [項目名の設定](prepare-data.md#column-mapping) で列名を確認 |
    | E103 | 希望列が見つからない | 「希望保育園ID列のパターン」を確認（例：`希望保育園ID_N`） |
    | E104 | 点数列が見つからない | 「点数列名」の設定を確認 |
    | E105 | 申請者 ID 列が見つからない | 「申請者ID」の設定を確認 |
    | E106 / E107 | 出力列名が重複している／既存列と重複している | 「出力設定」で別の列名に変更 |

    **E2xx：データの問題（ファイルの値）**

    | コード | 内容 | 対処 |
    |---|---|---|
    | E201 / E202 | ID 列に空欄／重複がある | 全行に一意の ID を設定 |
    | E203 / E216 | 年齢列に数値以外／0〜5 以外の値がある | 0〜5 の整数で入力 |
    | E204 | 点数列に整数以外の値がある | 小数・文字が混ざっていないか確認。15 桁超の点数が指数表記になっている場合は [15 桁制限](prepare-data.md#excel-15-digits) を参照 |
    | E205〜E208 | 保育所ファイルの ID・募集人数に空欄・負数・数値以外・重複がある | 該当列を修正 |
    | E209 / E211 | 希望列／在籍保育所 ID 列に、保育所ファイルにない ID がある | [レシピ 2](prepare-data.md#preferences) で無効コードを空欄化 |
    | E210 | 希望保育所が 1 件もない申請者がいる | 各申請者に希望を 1 件以上入力 |
    | E212 | 転園元の施設が希望列にも入っている | 希望列から転園元の ID を削除（転園元は専用列で扱います） |
    | E213〜E215 | きょうだい条件番号が無効／世帯内で不一致／きょうだい世帯なのに空欄 | [レシピ 3](prepare-data.md#siblings) を参照 |
    | E217 | 第 1 希望に対応する点数列に空欄がある | 第 1 希望の点数は全行に入力（第 2 希望以降は空欄可） |
    | E218 | [組み合わせファイル](prepare-data.md#siblings) に必要な列（世帯 ID・順位、宛名コード N・希望施設 N の対応するペア）が見つからない | 「項目名の設定」の「組み合わせデータ」で列名を確認 |
    | E219 | 組み合わせファイルの順位列に 1 以上の整数以外の値がある | 順位を 1 から始まる整数で入力 |
    | E220 | 組み合わせファイルの世帯 ID が申込者データに存在しない | 申込者データの世帯 ID と一致させる |
    | E221 | 組み合わせファイルの申請者 ID が申込者データに存在しない、または別世帯の申請者 ID が混入している | 組み合わせ行の世帯 ID と申請者 ID の対応を確認 |
    | E222 | 組み合わせファイルの希望施設 ID が保育所データに存在しない | 保育所データの ID と一致させる |
    | E223 | 新たに割り当てる保育所を 1 か所までに限るパターン（同保系 1〜3）なのに、きょうだい間に共通の希望施設がない | 共通の施設を希望列に追加するか、別保系（4〜7）に変更 |

    **E4xx：ファイル形式の問題**

    | コード | 内容 | 対処 |
    |---|---|---|
    | E401 | 対応していないファイル形式 | CSV または Excel（.xlsx / .xls / .xlsm / .xlsb）を選択 |
    | E402 | 全角・半角の違いだけの列名が混在している | 列名の重複を解消 |
    | E403 / E404 | 点数列の形式が混在している | 「共通 1 列」か「希望順位別の複数列」のどちらかに統一 |
    | E405 | CSV の文字コードが UTF-8 ではない | Excel で「CSV UTF-8 (コンマ区切り)」形式で保存し直すか、Excel 形式（.xlsx）のままアップロード |

    **E5xx：マッチング実行の問題**

    | コード | 内容 | 対処 |
    |---|---|---|
    | E501 | 実行不可能（INFEASIBLE） | きょうだい条件・入力データの不整合を確認 |
    | E502 | 制限時間内にマッチング結果が確定しない | データを絞り込むか、ログを添えて報告 |
    | E503 | ソルバー（計算エンジン）が予期しない状態で終了 | ログを保存して報告 |
    | E504 | マッチング結果の妥当性検証に失敗 | 入力データを確認し、解消しなければ報告 |

## 不具合の報告 {#report}

上記の対処で解消しない場合は、開発チームが状況を把握して修正できるよう、GitHub（ChilmAI の開発を公開している場所）の Issues にご報告ください。報告は誰でも閲覧できる公開の場に投稿されます。

1. [ChilmAI の Issues](https://github.com/CyberAgent/ChilmAI/issues) を開き、同じ症状の報告が既にないか検索してください。似た報告があれば、新規作成の代わりにその報告へコメントを追加してください。
2. 同じ報告がなければ、「New issue」から **Bug report**（不具合の報告）テンプレートを選んで作成してください。GitHub のアカウントが必要です。
3. テンプレートの各項目に、次の情報を記入してください。

    - ChilmAI・OS・ブラウザのバージョン
    - どの操作をしたときに起きたか（手順）
    - 画面のエラーメッセージ（エラーコードがあればコード番号も。下記のとおり、実データの値は伏せてください）
    - 入力ファイルの構造（下記のとおり、合成データのサンプル）
    - 黒いウィンドウに出ているログ（保存方法はこのページの末尾に記載しています。こちらも実データの値は伏せてください）

### 報告に含めてはいけない情報 {#no-real-data}

公開の場に投稿されるため、次の情報は Issue の本文・コメント・添付ファイルに含めないでください。

- 実在する個人情報（申請者の氏名、住所、生年月日など）
- 自治体データ、本番の入力ファイル、マッチング結果、設定ファイル
- 秘密情報、認証情報、その他の機密情報

再現のためにサンプルファイルが必要な場合は、実在する個人や組織を特定できない **合成データ**（架空の値で作り直したデータ）を使ってください。エラーの再現には、問題が起きる列と数行のデータだけで足りることが多いです。

**エラーメッセージとログも、そのまま貼り付けないでください。** ChilmAI のエラーメッセージには、問題が見つかった箇所を示すために、入力ファイルに実際に入っていた値（申請者 ID、世帯 ID、保育所 ID など）や、自治体で使っている列名がそのまま含まれることがあります。次のどちらかの方法で投稿してください。

- 貼り付ける前に、実データの値を `AAA001` のような架空の値へ置き換える（エラーコードと文章の形は変えないでください）
- 本番データではなく合成データで同じエラーを再現し、そのときのメッセージとログを投稿する

### 公開できない内容の報告先

問い合わせフォームにも、上記の [報告に含めてはいけない情報](#no-real-data) は送信しないでください。フォームは公開されない連絡手段ですが、実在する個人情報や自治体データの送信先ではありません。

- **脆弱性（セキュリティ上の欠陥）の可能性がある内容**：公開 Issue には投稿せず、[SECURITY.md](https://github.com/CyberAgent/ChilmAI/blob/main/SECURITY.md) に記載された報告先（プロジェクト問い合わせフォーム）へご連絡ください。
- **その他、公開の場に書けない内容**：同じ[問い合わせフォーム](https://docs.google.com/forms/d/e/1FAIpQLScAbG8AsVnXq8EPWNHtDCmI5ch1C1QPkGJJC9V-ubtx4BYYkw/viewform)からご連絡ください。通常の不具合報告は GitHub Issues をご利用ください。

??? note "黒いウィンドウのログを保存する方法"
    不具合が起きた直後に保存しておくと、その後の対応がスムーズです。

    1. 黒いウィンドウ（コマンドプロンプト）のタイトルバーを右クリック → 「編集」 → 「すべて選択」
    2. 反転表示された状態で Enter キーを押す（クリップボードにコピーされます）
    3. メモ帳などに貼り付けてテキストファイルとして保存

    保存したログを公開 Issue に投稿する場合は、[報告に含めてはいけない情報](#no-real-data) のとおり、実データの値を架空の値へ置き換えてください。
