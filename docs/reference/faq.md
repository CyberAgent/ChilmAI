# FAQ

## ChilmAI は何を自動化しますか

入力データのバリデーション、保育所の募集人数を超えない範囲での入所選考マッチング、結果データの整形を支援します。

## どの入力形式に対応していますか

CSV、XLSX、XLSM、XLSB、XLS に対応しています。

## 列名が既定値と違っても使えますか

使えます。列名マッピングで、実データの列名を ChilmAI の内部項目へ対応付けます。

## 自治体ごとの点数計算に対応できますか

`BasePreprocessor` を継承して、点数列やきょうだいパターンを生成できます。

## Web UI は必須ですか

必須ではありません。アプリケーションに組み込む場合は、`MatchingService` を使う Python API が基本の入口です。一方、**プログラミングなしでブラウザの操作だけで試したい場合**は、Web UI が入口になります（[自治体の方へ](web-ui/index.md)）。
