# 自治体の方へ

ChilmAI の Web UI（ブラウザで操作する画面）は、プログラミングの知識がなくても、ブラウザの画面操作だけで保育所入所選考（マッチング）を試せるツールです。基本の操作は **「① データをアップロードする → ② 入所選考を実行する → ③ 結果を Excel でダウンロードする」** の 3 つだけです（申込者データと保育所データは Excel または CSV 形式でアップロードできます）。

このガイドは、**自治体で保育所利用調整を担当する職員の方**に向けて、準備から結果の確認までを作業の順番どおりに説明します。

ChilmAI のマッチングの仕組みは、人工知能分野の国際会議 AAAI-24 に採択された研究論文に基づいており、点数順の優先やきょうだい同時入所・転園を扱えることが理論的に裏付けられています。詳しくは [背景となる研究](../../development/architecture.md#research-background) を参照してください。

!!! note "本ガイドの用語"
    - **申込者データ / 保育所データ**：アップロードする 2 つの必須ファイルの呼び名です（画面の表示に合わせています）。きょうだいの申込を別ファイルで管理する自治体は、任意の「組み合わせデータ」も使います
    - **申請児童**：申込 1 件（データ 1 行）にあたる子どもを指します。画面や列名では「申込者数」「申請者ID」のように「申込者」「申請者」とも表記されますが、いずれも同じ子どものことです
    - **施設 / 保育所**：同じ意味で使っています

!!! note "データはお使いの PC の内部でのみ利用されます"
    ChilmAI はお使いの PC の中だけで動作します。アップロードしたデータやマッチング結果がインターネットや庁内ネットワークに送信されることはありません。インターネット接続がない環境でも動作します。アップロードしたファイルがアプリ内に保存され続けることはありません（処理の都合で PC の一時フォルダに一時ファイルが作成される場合がありますが、利用者が削除などの操作をする必要はありません）。

## 全体の流れ

初めて使う場合は、まずデモデータで一連の流れを体験し（フェーズ 1）、続けて自分のデータ形式に合わせた評価・検証に進みます（フェーズ 2）。各項目の詳しい実施方法はリンク先で説明しています。

### フェーズ 1: まずデモで試す（約 30 分）

ChilmAI をダウンロードして起動し、同梱のデモデータでマッチングを実行して結果の Excel を開くところまでを一気に体験します（Windows 11 の PC が必要です。[クイックスタート](quickstart.md)・約 30 分、[動作環境](quickstart.md#requirements)）。

ここまでで、ChilmAI の動き（点数順の優先・転園・きょうだい同時入所）と結果の見方がわかります。**自分のデータ形式でも試したくなったら、以降のフェーズ 2 に進んでください。**

### フェーズ 2: 自分のデータ形式で評価・検証する

自治体ごとの帳票を ChilmAI が読める形に整え、自分のデータ形式でマッチングを評価・検証します。デモと違い帳票を整える作業が中心で、帳票の状態によっては数時間程度かかります。

!!! warning "実際の個人情報を扱う前に確認してください"
    Web UI は ChilmAI を手軽に試すための **評価・検証用** の実装で、認証・監査ログ・データ保護などの本番運用に必要な機能は含まれていません。実際の個人情報を含むデータで評価・検証する場合は、先に庁内の情報システム担当に相談のうえ、セキュリティポリシーに沿って必要な対策を判断・実施してください（詳細は下記の [利用にあたっての注意](#usage-notes)）。

1. 申込者データを ChilmAI が読める形に整形する — 特に、点数とタイブレーク（同点のときに順位を決める項目）を 1 つの点数列にまとめる作業と、きょうだい条件の設定（[自分のデータで使う](prepare-data.md)・帳票により数時間程度）
2. 整形して確定した列名を「項目名の設定」で登録する（[項目名の設定](prepare-data.md#column-mapping)）
3. 実データでデータ確認 → 選考実行 → 結果確認まで行う（[選考の実行と結果の見方](run-results.md)・約 30 分）

## 利用にあたっての注意 {#usage-notes}

Web UI は、ChilmAI を手軽に試すための **評価・検証用** の実装です。本番運用に必要な認証、権限管理、監査ログ、運用監視、データ保護、脆弱性対応は含まれていません。実際の個人情報を含むデータで利用する場合は、庁内の情報システム担当に相談のうえ、セキュリティポリシーに沿って、必要な対策を利用者側で判断・実施してください（[セキュリティ](../security.md)）。

ChilmAI は Apache License 2.0 のもとで公開されている OSS です。実運用での結果や運用設計は、利用する自治体・組織の責任で確認・判断してください（[ライセンス](../license.md)）。

??? note "開発者向け：ソースコードから起動する場合"
    Web UI は `apps/api` にある FastAPI アプリケーションの一部です。リポジトリから起動する手順は [インストールと実行](../../getting-started/quickstart.md) を参照してください。

    業務システムへ組み込む場合は、Web UI ではなく [Python API](../../api/python.md) または [サーバ API](../../api/reference-app.md#server-api) を起点にしてください。
